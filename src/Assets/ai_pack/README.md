# CareerSense — Artificial Intelligence Fellowship Asset Pack

Production-ready asset pack for recreating the supplied AI Fellowship landing page in React.

## Included

- CareerSense primary logo + standalone brand mark
- High-resolution AI Fellowship hero student image in PNG and WebP
- Five hero AI/ML dashboard cards:
  - Model Accuracy
  - Prompt Quality
  - Agent Workflow
  - Automation Tasks
  - Inference Results
- Six learning-outcome illustrations:
  - AI Foundations
  - Prompt Engineering
  - LLM Applications
  - AI Agents & Automation
  - Model Evaluation
  - Capstone Project
- Ten tools / technology assets:
  - Python
  - Prompting
  - LLM APIs
  - LangChain-style orchestration icon
  - Vector Databases
  - Hugging Face-style ML icon
  - Pandas
  - Streamlit-style app icon
  - GitHub-style developer icon
  - APIs
- AI Fellowship certificate
- Fellow digital ID card
- Ready-to-place certificate + ID credential stack
- "Why Join?" AI hologram / dashboard illustration
- Bottom CTA AI dashboard illustration
- Utility UI icons
- Hero background and CTA dot pattern
- JSON asset manifest

## Formats and quality

- UI icons and illustrations: SVG + high-resolution PNG
- Credential artwork: SVG + 2400px PNG
- Hero: PNG + optimized high-quality WebP
- Large illustrations: scalable SVG + 2400px/2700px PNG
- Backgrounds: scalable SVG + 2x PNG

## Recommended React usage

```jsx
<img src="/assets/ai/learning/ai-agents-automation.svg" alt="" />
<img src="/assets/ai/hero/hero-ai-fellowship-student.webp" alt="" />
<img src="/assets/ai/credentials/credential-stack.png" alt="" />
```

Prefer SVG for interface artwork and WebP for photographic content.
