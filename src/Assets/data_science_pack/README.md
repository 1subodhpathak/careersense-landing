# CareerSense — Data Science Fellowship Asset Pack

Prepared to reproduce the supplied CareerSense Data Science Fellowship page in React at high visual fidelity.

## Included
- CareerSense logo and brand mark
- Data Science hero photography in PNG + WebP
- 4 hero ML/analytics cards
- 6 learning-outcome illustrations
- 10 tool/technology icons
- Data Science fellowship certificate
- Data Science Fellow ID card
- Ready-to-place certificate + ID stack
- Why Join data-science illustration
- CTA AI/dashboard illustration
- Shared utility icons for stats, audience, and footer benefit strip

## Recommended React usage
Use SVG assets for icons/illustrations and WebP for the hero photo.

```jsx
<img src="/assets/data-science/learning/machine-learning.svg" alt="" />
<img src="/assets/data-science/hero/hero-data-science-student.webp" alt="" />
```
