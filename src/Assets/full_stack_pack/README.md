# CareerSense — Full Stack Developer Fellowship Asset Pack

Production-ready assets for recreating the supplied Full Stack Developer Fellowship page in React.

## Included

- CareerSense logo + standalone mark
- High-resolution Full Stack hero student image (PNG + WebP)
- Floating code panel
- Project Progress dashboard card
- Skills Graph dashboard card
- Technologies Used card
- 6 learning illustrations
- 15 tools / technology assets:
  HTML5, CSS3, JavaScript, React, Next.js, Node.js, Express.js, MongoDB,
  SQL, Git, GitHub, Docker, AWS, Firebase, Postman
- Full Stack Developer certificate
- Full Stack Fellow ID card
- Combined certificate + ID stack
- Why Join developer workstation illustration
- Full Stack CTA laptop / cloud / phone illustration
- Shared utility icons
- Hero background and CTA dot pattern
- Asset manifest JSON

## Formats

- Icons and illustrations: SVG + 1024px PNG
- Credentials: SVG + 2400px PNG
- Hero: high-quality PNG + WebP
- Large illustrations: SVG + 2700px PNG
- Backgrounds: SVG + 2x PNG

## React usage

```jsx
<img src="/assets/full-stack/learning/frontend-development.svg" alt="" />
<img src="/assets/full-stack/hero/hero-full-stack-developer.webp" alt="" />
<img src="/assets/full-stack/credentials/credential-stack.png" alt="" />
```

Prefer SVG for UI artwork and WebP for photographic content.

## Core palette

- Navy: #071B49

Assets are separated into reusable React-ready components rather than screenshot slices, so they stay sharp and responsive on retina and 4K displays.
