## Formats

- Interface icons / illustrations: SVG + 1024px PNG
- Credential artwork: SVG + 2400px PNG
- Hero photography: high-quality PNG + WebP
- Large illustrations: SVG + 2700px / 2820px PNG
- Backgrounds: scalable SVG + 2x PNG

## React usage

```jsx
<img src="/assets/uiux/learning/user-research.svg" alt="" />
<img src="/assets/uiux/hero/hero-uiux-designer.webp" alt="" />
<img src="/assets/uiux/credentials/credential-stack.png" alt="" />
```

Prefer SVG for UI artwork and WebP for photography.
