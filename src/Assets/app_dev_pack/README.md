# CareerSense — App Developer Fellowship Asset Pack

Production-ready assets for recreating the supplied App Developer Fellowship page in React.

## Included
- CareerSense logo + mark
- High-resolution App Developer hero image (PNG + WebP)
- Floating mobile-development code panel
- Project Progress dashboard card
- Apps Built bar-chart card
- Top Skills Gained card
- 6 learning illustrations
- 10 tool assets: React Native, Flutter, JavaScript, TypeScript, Node.js, Firebase, MongoDB, Express.js, Git & GitHub, Postman
- App Developer certificate
- App Developer Fellow ID card
- Combined certificate + ID stack
- Why Join mobile-development illustration
- Bottom CTA mobile / Apple / Android / code illustration
- Shared utility icons
- Hero background and CTA dot pattern
- Asset manifest

## Formats
- UI icons and illustrations: SVG + 1024px PNG
- Credentials: SVG + 2400px PNG
- Hero: high-quality PNG + WebP
- Large illustrations: SVG + 2700px PNG
- Backgrounds: SVG + 2x PNG

## Recommended React usage
```jsx
<img src="/assets/app-development/learning/mobile-app-development.svg" alt="" />
<img src="/assets/app-development/hero/hero-app-developer.webp" alt="" />
<img src="/assets/app-development/credentials/credential-stack.png" alt="" />
```

Prefer SVG for UI artwork and WebP for photography.
