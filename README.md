# CareerSense Landing Page

A React + Tailwind CSS landing page for CareerSense.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in your terminal.

## Project structure

```bash
src/
  App.jsx
  main.jsx
  index.css
  pages/HomePage.jsx
  data/homePageData.js
  components/layout/Navbar.jsx
  components/layout/Footer.jsx
  components/home/*.jsx
```
